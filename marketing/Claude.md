## Marketing and Video Production Agent

When asked to create marketing materials, product videos, feature demonstrations, or social media content for this application:

### Product understanding
- Read the documents inside `/marketing/`.
- Inspect the current application and verify the documented features.
- Identify the target audience, core benefits, and product positioning.
- Never invent capabilities, testimonials, statistics, or results.

### Asset collection
- Use available browser automation tools to run and inspect the application.
- Use a dedicated demo environment with realistic, non-sensitive data.
- Capture screenshots of the dashboard and important features.
- Record short demonstrations of the major user workflows.
- Prefer reproducible automated capture scripts.
- Save an asset manifest mapping recordings to features and product versions.
- If automatic capture is unavailable, request only the missing assets.

### Video production
Prepare these video types:

1. Full application showcase: 45–60 seconds.
2. AI presenter / UGC advertisement: 30–45 seconds.
3. Individual feature demonstrations: 15–30 seconds each.
4. Short product teaser: 10–15 seconds.

Create a script, storyboard, and shot list before generation.

Use Higgsfield for AI presenters, cinematic scenes, and supporting creative assets where appropriate. Preserve real screenshots and screen recordings when showing actual product functionality.

Get approval before spending generation credits.

### Social media preparation
For every approved video:
- Create a clear, platform-specific hook.
- Write the accompanying post caption.
- Suggest a suitable CTA and relevant hashtags.
- Produce a vertical version for short-form social channels.
- Create a landscape version where beneficial.
- Generate a thumbnail concept.
- Record the content in the marketing calendar.

Default to one main video per post, with each post focused on a distinct audience problem or product benefit.

### Quality control
Verify that:
- All demonstrated features actually exist.
- All product text and UI elements are accurate.
- No sensitive information appears.
- Audio, captions, and visuals are synchronized.
- Branding is consistent.
- Final assets have been reviewed and approved.

Do not publish automatically without explicit authorization.

## Product Marketing Context

This workspace contains multiple applications and services that together form one product.

The shared product marketing documentation is located in `/marketing/`.

For marketing-related tasks:
- Read `marketing/strategy.md` to understand the product, target audience, positioning, and messaging.
- Read `marketing/features.md` to understand implemented capabilities, user benefits, supported platforms, and workflows.
- Treat these documents as the starting point for marketing activities, but verify relevant claims against current implementation when necessary.
- Never market incomplete or planned functionality as available.
- Use consistent product terminology and brand messaging across iOS, web, and other platforms.

When implementing or changing a user-facing feature, check whether the marketing documentation needs updating. If it does, update the relevant sections and preserve existing verified information.

When asked to create marketing videos, use these documents to select features, write scripts, create storyboards, and identify which screens and workflows should be recorded.
